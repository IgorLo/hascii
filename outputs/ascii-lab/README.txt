GLYPH LAB — локальный экспериментальный прототип

ЗАПУСК
Дважды нажмите START.cmd. Нужен Node.js 22 или новее (на этом компьютере установлен).
Откройте http://127.0.0.1:4173. Не закрывайте окно сервера, пока используете страницу.
Если сервер уже запущен, достаточно открыть ссылку. Исходники TypeScript находятся в src,
готовая браузерная версия — в dist. Установка зависимостей для запуска не нужна.
После изменения TypeScript: npm install, затем npm run build. Сервер: npm start.

ВОЗМОЖНОСТИ
Загрузка/перетаскивание изображения; оригинал и результат рядом; экспорт PNG.
Коррекция яркости/контраста/насыщенности. Пиксельная сетка, палитры, три вида дизеринга.
ASCII на однотонном фоне или поверх размытого пиксельного изображения.
Редактируемые наборы Unicode, шрифты, размер, горизонтальные/вертикальные интервалы.
Подбор по яркости либо смешанный по яркости и форме.
Импорт палитр Lospec по ссылке или slug (например sweetie-16).
Палитры и набор символов сохраняются в localStorage браузера для этого адреса.
Рабочее разрешение ограничено 1600 px по длинной стороне; экспорт имеет тот же размер.
Настройки эффектов и загруженное изображение не сохраняются после перезагрузки.

УСТРОЙСТВО И ОГРАНИЧЕНИЯ
Web Worker выполняет обработку отдельно от интерфейса. Запуски ограничены интервалом
180 мс, одновременно работает только один запрос. После него берутся последние настройки.
Изображения не отправляются на сервер. Локальный сервер отдаёт статические файлы и
запрашивает только JSON выбранной палитры у Lospec. Сервер слушает только 127.0.0.1.
Фоновая пикселизация и сетка ASCII независимы: размер ASCII-сетки задаётся шрифтом и интервалами.
Без ограничения палитры дизеринг отключён, поскольку нет квантования цвета.
Прозрачность входного изображения композитится на чёрный до коррекции.
Сглаживание шрифта, прозрачность наложения и blur создают промежуточные цвета.
До 512 уникальных знаков участвуют в подборе. Отсутствующие в шрифте Unicode-знаки
могут отображаться заменой; emoji и составные grapheme-кластеры не поддерживаются точно.
Широкие знаки вписываются по ширине ячейки; атлас и результат используют одинаковую геометрию.
Подбор формы — экспериментальная локальная метрика, не нейросеть и не полная реализация AISS.
Результат зависит от изображения, размера ячеек, шрифта и набора знаков.
В режиме наложения используется светлая полярность символов независимо от однотонного фона.
Встроенный sample.png — предоставленный пользователем референс, уже обработанный растром.
Для оценки качества преобразования желательно загрузить обычное фото.

АЛГОРИТМЫ И ИСТОЧНИКИ
Floyd–Steinberg: распространение ошибки 7/16, 3/16, 5/16, 1/16.
Atkinson: шесть соседей по 1/8, четверть ошибки отбрасывается.
Bayer: стандартная пороговая матрица 4x4; в цветном режиме порог смещает RGB перед
поиском ближайшего цвета по взвешенной RGB-дистанции. Это простой художественный вариант,
не оптимальный perceptual/OKLab palette dithering.
Обзор схем: https://tannerhelland.com/2012/12/28/dithering-eleven-algorithms-source-code.html
Lospec JSON: https://lospec.com/palettes/api
Идея структурного подбора: https://research.monash.edu/en/publications/structure-based-ascii-art/
Здесь: растр каждого знака уменьшается до 6x8, нормализуется, сравнивается с участком
исходного изображения через корреляцию и ошибку плотности. Символы анализируются до дизеринга.
Референс интерфейса: https://pixelartvillage.com/

ПРОВЕРКИ
TypeScript strict: сборка проходит.
Проверены принадлежность пиксельного результата палитре для всех алгоритмов,
нулевая сила дизеринга, покрытие полутонового поля, запуск и обработка в браузере.
В браузере проверены пресеты, ASCII, наложение/форма, добавление Unicode-наборов,
импорт Sweetie 16 и Lost Century, загрузка изображения и скачивание PNG.
Независимое код-ревью: исправлены выход Unicode-глифов за ячейки, неправильная
полярность в overlay и исключение при разборе некорректного URL локальным сервером.

ОБНОВЛЕНИЕ ПРЕВЬЮ И ПУСТЫХ ЯЧЕЕК
Режимы превью: рядом, сверху вниз, только результат. Последние два занимают всю ширину; размер PNG не меняется.
Галочка «Разрешать пустые ячейки» явно включает пробел в подбор независимо от набора. Если выключена, пустые глифы исключаются.
Порог пропуска измеряет локальное стандартное отклонение яркости до дизеринга (шкала 0–255). При значении >0 ровные участки заполняются сплошными ячейками цвета из палитры (или исходного изображения без палитры). Непрозрачность символов не меняет эти заливки. При 0 заливка отключена, пробел только участвует в подборе.
В чистом ASCII настройки пикселизации отключены с пояснением: размер символов и интервалы задают собственную сетку.



ОФОРМЛЕНИЕ TERMINAL
Весь интерфейс использует моноширинный шрифт. Символьные рамки, кнопки в скобках, чекбоксы [x] и ASCII-полосы ползунков. Ползунки сохраняют нативное управление мышью и клавиатурой; декоративные полосы скрыты от accessibility tree. Skin: dist/terminal.css.


НЕПРОЗРАЧНОСТЬ ФОНА
В режиме «Фон + ASCII» отдельный ползунок смешивает пиксельный слой с выбранным однотонным фоном. Непрозрачность символов независима. В этом режиме однотонные ячейки сохраняют уже отрисованный пиксельный фон, включая его blur и opacity, а не перекрывают его непрозрачной заливкой.
