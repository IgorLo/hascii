# Мобильные инструменты с настоящим превью

Пользователь выбрал гибрид двух показанных макетов и поручил собрать и запустить реальное приложение. Короткая группа (до трех числовых параметров) показывает ползунки вместе; «Тон» показывает яркость, контраст и насыщенность с включателем в заголовке. Длинные группы, в частности ASCII, используют один Slider и горизонтальную ленту названий параметров. Лента переиспользует композицию ModePicker с публичными Button/IconButton и штатной прокруткой UI-kit. Выбор параметра не открывает еще один экран.

Результат остается над немодальной панелью; в landscape панель справа. Контролы не перемещаются и не становятся прозрачными во время drag. Список числовых настроек следует условиям нынешнего UI: выключенные и неприменимые поля не появляются, их значения сохраняются. Полные формы стиля/символов, импорт и Фото открываются отдельно без обязательного превью. Полные формы переиспользуют существующие Controls, а не новый дубликат 43 настроек. Вернуться из числовой строки полной формы можно прямо к выбранному ползунку основной панели.

Back снимает открытый уровень: подробности → инструменты → обычное превью. Смена раздела заменяет состояние того же уровня; выбор значения и параметра историю не меняет. Используется публичный shallow routing установленного SvelteKit 2.70.3, без распознавания свайпов. PalettePicker сохраняет свой публичный Popover и получает управляемую открытость для согласования Back. Нативное закрытие overlay синхронизируется с тем же состоянием, без двойного Back. Из корневого превью разрешен обычный выход браузера. На desktop мобильное временное состояние завершается; bitmap/Settings сохраняются.

Select расположения переносится под изображение; редактирование временно показывает только результат, выбранное сравнение восстанавливается после закрытия панели. Подписи «Оригинал» и «Результат» без номеров. Вокруг canvas — тонкая рамка приложения с минимальным зазором вместо внутренне padded Panel. Время последнего готового рендера выводится рядом с характеристиками цветом muted. Загрузка/обработка, ошибки и предупреждения остаются доступны; время не выдается за актуальное во время незавершенного рендера.

Сохраняются все 43 поля модели, семь режимов и их порядок, defaults, четыре пресета без отмены, числовые диапазоны, PNG, HEIC, Lospec и существующая персистенция. Обработка изображений остается в браузере; сервер получает только palette slug. Математика renderer и зависимости не меняются. UI-kit 0.3.0 применяется через публичные API; внутренних override/копий нет.

Проверка: unit-правила доступности числовых параметров; browser tone/длинная группа/вложенный экран/Back–Forward/Escape/повторное открытие/desktop breakpoint; размеры 320×640, 393×852, landscape и desktop; реальные изменения canvas и PNG/HEIC/Lospec через существующие E2E. До передачи ссылки выполнить готовую production-сборку и основной сценарий на узком и широком экранах. Запустить устойчивый локальный сервер, подтвердить readiness в следующем вызове и открыть для пользователя. Физический жест стороннего WebView остается отдельной проверкой на устройстве.

## Рассмотренные варианты

- Все ползунки сразу: выбрано для коротких групп, включая «Тон»; длинные формы слишком уменьшают изображение.
- Один ползунок с прямым выбором: выбрано для длинных групп, без прежнего списка/возврата на каждую регулировку.
- Полноэкранная форма: оставлена для длинного текста/импорта/загрузки и дополнительных настроек, с нормальным Back.

Основание: одобрение гибрида в текущем сообщении пользователя; детали композиции и границы компонентов — выбор исполнителя для реального превью. Реализация в ветке `codex/mobile-tools-preview`, база `eb9f0bb1dc2e8dda305f7f0b93b7277f13b5fe3d`; Hub `ff148a1644f71a31cb599cab46a1e0752d2dbc64`.
